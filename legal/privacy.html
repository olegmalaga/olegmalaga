Политика конфиденциальности

Последнее обновление: 28 октября 2026

1. Какие данные обрабатываются

  • OAuth-токены доступа и обновления TikTok;
  • идентификатор пользователя TikTok (open_id);
  • метаданные видео для публикации (файл, подпись, настройки приватности, статус публикации).

2. Цель обработки

Данные используются исключительно для публикации видео в подключённый TikTok-аккаунт Espresso LV.

3. Передача данных

Мы не продаём и не передаём данные третьим лицам, кроме TikTok в объёме, необходимом для публикации.

4. Хранение

Токены хранятся в защищённом виде только пока приложение подключено; при отзыве доступа они удаляются. Временные файлы видео удаляются после публикации. Доступ можно отозвать в настройках TikTok в любой момент.

5. Политика TikTok

На платформе TikTok действует собственная политика конфиденциальности TikTok.
